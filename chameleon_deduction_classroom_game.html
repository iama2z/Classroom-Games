⚙️ Firewall-Proof Google Sheets Multiplayer Backend

Quick 3-Minute Setup Instructions:

  1. Create a new blank Google Sheet on your personal Google account.
  2. Click Extensions → Apps Script in the top menu.
  3. Delete any placeholder code in Code.gs and paste the complete script below.
  4. Save, select setupTeacherSettings in the Apps Script function dropdown, and click Run. Approve Google's authorization prompt.
  5. Return to the sheet. In the new TeacherSettings tab, enter your private passphrase (12–256 characters) in B2. Keep the entire spreadsheet private.
  6. Click Deploy → New deployment → Select type: Web app.
  7. Set Execute as: Me, and Who has access: Anyone (so students don't need to log in).
  8. Copy the Web app URL (`https://script.google.com/macros/s/.../exec`) and paste it into the box above!

Updating an existing setup: replace Code.gs, run setupTeacherSettings and set B2, then use Deploy → Manage deployments → Edit → New version → Deploy to keep the same URL. Do not clear script properties; they hold your rooms. Remove any other old web-app deployments that still expose unauthenticated writes.
